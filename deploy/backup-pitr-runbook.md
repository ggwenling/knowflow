## 2. 备份范围

- PostgreSQL（`knowflow`，含 pgvector）。
- MinIO 对象存储（文档原文）。
- 配置与版本：镜像 digest、compose/部署清单、`PRICE/POLICY` 哈希（不含密钥值）。

## 3. 日备步骤

1. 触发数据库逻辑备份（`pg_dump -Fc`）并记录开始/结束时间。
2. 同步 MinIO bucket 到异地存储（版本化/对象锁），记录对象数。
3. 计算备份 SHA-256，写入清单。
4. 上传到异地副本，校验下载 SHA-256。
5. 记录备份大小、耗时、失败重试。

## 4. PITR

- 开启 WAL 归档到异地对象存储；验证归档连续性。
- 恢复演练：在隔离实例回放到指定时间点，跑迁移状态检查与只读查询。
- 记录恢复点、耗时、数据差异。

## 5. 恢复演练

```powershell
# 示例：在隔离 compose 项目恢复
docker compose --project-name knowflow-restore -f infra/compose.yml --env-file infra/.env up -d postgres minio
# 还原 dump，校验 schema 版本与关键表计数
# 启动 api/ai/web，执行 /health/ready 与一次合成问答
```

通过标准：

- schema 版本正确；
- 关键表计数与备份清单一致；
- 文档对象可读；
- 冒烟通过；
- 隔离资源清理。
