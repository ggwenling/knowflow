# 私有盲测准备与执行

保管者由项目负责人担任。准备原创合成的 TXT/Markdown 资料和 20 道问题：15 道可回答、5 道资料不足；覆盖多证据、版本冲突、来源定位以及不同表达。使用与公开 60 题不同的资料及事实组，不把现有公开的 20 题验证分组当作盲测。

对每题记录答案要点、可回答性、原文版本、证据片段和 Unicode 码点位置；不可回答题记录拒答理由。资料、问题、答案及原始预测保存在仓库外的受控目录，不放进开发聊天、Git 或公开 CI。保管者完成核验后记录数据集文件的 SHA-256 承诺和时间，保留原始数据以备独立评分。

实现方冻结代码提交、模型配置、提示词、评测规则及质量门后，独立评测会话由保管者提供受控访问：推理只输入问题及检索资料，金标只交给离线评分。每份预测、审核结果和配置绑定相应摘要；结果仅公开分母、指标、脱敏错误类别和完整性证据。核对预算台账，全部真实模型调用共享人民币 10 元限额；无法可靠估价或余额不足时停止。

采用已登记的 Recall@5、MRR@10、答案支持率、引用准确率、拒答和误拒答门槛；5 道不可回答题需全部正确拒答才能达到 90%。测试失败后保留结果，不以同一留出集反复调参；再次正式验收须使用新的独立题集。评分覆盖、数据集哈希、运行版本或预算证据缺失时标记未完成。
