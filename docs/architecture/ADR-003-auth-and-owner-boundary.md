# ADR-003：基础认证与个人知识库边界

- 状态：`PROPOSED`，JP-01 G3 开发候选；等待 Q 独立审阅与 M 消费确认。
- 对应：KF2-012/013；公共消息候选 `0.2.0-draft.4`。
- 作者：Codex-A；日期：2026-10-30（Asia/Hong_Kong）。

## 认证选择

- 注册/登录接受 email + password JSON；email 去除首尾空白并转为小写；密码长度为 12–128 字符。
- PBKDF2 编码器保存密码摘要，不保存或返回摘要。未知用户和错误密码返回相同 401 错误。
- 成功认证创建 32 随机字节 opaque Bearer token，8 小时后过期。数据库只保存 token SHA-256；logout 撤销当前 session。没有 Cookie、refresh token 或多 session 撤销接口。
- 认证只在 `database` Spring profile 启用；默认进程保留 health-only 骨架。用户身份来自当前数据库中的未撤销、未过期 session，不接受请求体中的 user/owner ID。

## 所有者隔离与删除

- 创建、列出、读取和删除知识库时，owner 始终从认证 principal 派生，并进入 SQL 条件；client 提供额外 `owner_id` 会被作为未知 JSON 字段拒绝。别的用户、不存在和已删除的知识库返回同一 404。
- 逻辑删除在一个事务中标记知识库和其 ACTIVE 文档为 `DELETED`，并取消 QUEUED/RUNNING 索引任务、清除租约。内容版本对象和索引行保留以供后续清理；实际对象存储/向量回收尚未接通，待 KF2-014/024 依赖落实。
- 任何后续文档或问答查询必须同时检查知识库/文档可见状态。新增文档任务时需要与删除使用兼容的行锁/状态检查，防止删除提交后产生新任务。

## 待复核与未实现

注册冲突使用通用错误正文，但 409 仍可能暴露邮件地址冲突。登录速率限制、邮件验证、密码重置、刷新/全设备撤销、浏览器 token 持久化和会话清理未实现；M/Q 需在产品接入前确认策略。当前实现仅满足 A 线本地开发验收，不表示账户体验或 KF2-004 已冻结。
