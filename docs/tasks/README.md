# 任务卡索引

本目录存放各任务的执行任务卡，由任务作者填写；计划包原文在 `docs/planning/v0.2`，不得改写。任务卡状态以卡内“最终状态”字段为准；未获 Q 结论与集成验证前，不把任务记为 DONE。

## 执行任务卡模板

```text
任务ID/标题：
负责人/实际Agent：
目标/本次不做：
真实依赖及已验收版本：
开发可用Mock/限制：
基线SHA/分支/worktree：
允许修改/禁止修改文件：
契约版本/输入输出/错误与边界：
工作步骤（建议2—4步）：
完成条件：
验证命令/环境/结果/未执行原因：
目标SHA/变更文件：
阻断项/风险/下一步：
Q审阅记录/修复SHA/复核：
实际集成版本/检查/最终状态：
```
