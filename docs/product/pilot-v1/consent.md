# 知情同意（Pilot v1 模板）

请在实际使用前由项目负责人/法务确认；本文件不是法律意见。

## 研究目的

了解研发人员在真实文档中定位并核验事实的过程，评估带引用问答是否有帮助。

## 参与内容

- 30–45 分钟任务：使用传统搜索/文档浏览与 KnowFlow 问答完成 3 个任务。
- 主持人在场，可能要求边做边说出想法。
- 记录：任务成功/失败、耗时、引用核验情况、简短访谈。
- 录屏/录音（可选，单独勾选）。

## 数据

- 不收集与任务无关的个人信息。
- 结果以匿名 ID 与聚合形式保存。
- 录屏/录音仅用于研究分析，按项目保留期删除。
- 不上传真实公司机密资料；使用提供的合成/公开材料。

## 风险与退出

- 任务可能略有疲劳；可随时休息或退出。
- 退出不产生任何不利后果，已收集数据可按要求删除。
