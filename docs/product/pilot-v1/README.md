# KnowFlow 真实用户试用 v1（2026-11-08）

状态：**执行材料已准备；未招募、未执行、无真实数据**。本目录不包含任何伪造的参与者记录。

## 目标

验证研发用户在真实资料上能否：

1. 找到并核验规范/ADR 中的关键事实；
2. 判断答案是否有足够证据；
3. 在两周内愿意再次使用。

## 设计

- 参与者：3–5 名成年研发人员（开发、测试、维护），最近一个月查过中文项目规范或 API 文档。
- 对照：传统搜索/文档浏览 vs KnowFlow 带引用问答；顺序随机化并记录。
- 任务：3 个，单题上限见任务脚本；允许超时并保留。
- 记录：成功率、耗时、引用核验耗时、置信度、两周复用天数与任务数、退出原因。
- 分析：按参与者/任务/方法列成功数与时间中位数/范围；样本小，不做显著性宣称。

## 文件

- `screener.md` — 招募筛选与排除。
- `consent.md` — 知情同意与数据边界。
- `task-script.md` — 任务、成功标准、主持脚本。
- `metrics-template.csv` — 记录模板（空表）。
- `interview-guide.md` — 访谈提纲。

## 不能替代

- 私有盲测、质量门与三端签收；
- 真实模型的质量/费用结论；
- 生产可用性验收。

## 证据与合规

- 不记录与任务无关的个人信息；录屏/录音需单独同意。
- 结果只以聚合与匿名 ID 呈现。
- 试用后问题必须回到缺陷/修复/复测闭环，不能只写“用户满意”。
