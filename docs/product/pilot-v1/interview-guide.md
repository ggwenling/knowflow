# 访谈提纲（Pilot v1）

时间：10–15 分钟。保持开放，不引导答案。

1. 你刚才如何判断一个答案是否可信？哪一步最费时？
2. 引用/原文定位对你的判断有帮助吗？哪里不够？
3. 传统搜索和问答，各自最适合什么场景？
4. 有没有一次你宁愿自己翻文档，也不愿用问答？为什么？
5. 如果答案说“证据不足”，你觉得可信吗？你会怎么继续？
6. 移动端/窄屏使用场景存在吗？你会用它做什么？
7. 接下来两周，你预计会在什么任务里再次使用？频率如何？
8. 最想删掉/保留的一个功能是什么？
9. 有没有让你担心数据范围或权限的地方？
10. 其他补充。
