# 招募筛选（Pilot v1）

## 纳入条件

- 成年（18+），当前从事开发、测试或维护工作。
- 最近一个月有查询中文项目规范、API 文档或 ADR 的实际经历。
- 能使用桌面浏览器并完成 30–45 分钟远程/现场任务。
- 愿意在知情同意后参与录屏或笔记记录（可拒绝录音）。

## 排除条件

- 参与过本产品需求/设计/评测，或已看过本任务材料。
- 无法独立阅读中文技术文档。
- 与被测资料存在直接利益关系（如资料作者本人评估自己的规范）。
- 不愿签署知情同意或拒绝任何数据采集。

## 招募信息模板

```text
我们在做一次 30–45 分钟的研发文档检索试用，比较“传统搜索”和“带引用的问答”。
需要你最近一个月查过 API 文档/规范/ADR。
会记录任务结果与耗时；录屏/录音单独征得同意。
不收集与任务无关的个人信息；可随时退出。
报酬：<按项目规定填写>
```
