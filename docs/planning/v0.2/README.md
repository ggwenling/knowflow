## 建议阅读顺序

先读项目计划第二章的交付范围和第三章的角色分工，再看任务总览；实际派工时使用协作手册中的角色提示词及单任务卡。

- A：Codex Coding Agent 1，Java/权限/任务/版本/公共契约，兼任集成协调。
- B：Codex Coding Agent 2，Python/RAG/解析/索引/评测。
- M：Muse，前端/基础设施/端到端/试用支持，属于主线研发。
- Q：Code Review Agent，滚动审阅全部主线任务，另有最终审阅任务KF2-044。

主线任务数量：A 19项、B 18项、M 18项；Q另有1项最终审阅任务，日常审阅覆盖所有主线任务。任务数量不是工作量估计。

## 相对V0.1的主要变化

1. 将双主线调整为2个Codex + 1个Muse主线、1个独立审阅角色。
2. 收缩首版为个人账号隔离、三种格式、向量基线、可核验单轮问答；团队/混合检索/重排/多轮后移。
3. 将真实页面与闭环前移至第3—4周目标窗口；十周作为待校准排期。
4. 明确Java状态所有权、Python索引权限、共享文件单写与审阅绑定SHA。
5. 增加隐私模式、资源边界、留出评测和两周真实试用，分别记录工程与产品验收。
6. 新编号KF2-*保留原KF-*基线，通过兼容性任务建立映射。
