## P2

### P2-1：删除登录页旧样式时连带破坏工作台标题样式

- 位置：`apps/web/src/components/workspace.module.css:5`。
- 问题：原规则 `.topbar h1,.authCard h1{margin:7px 0 0;font-size:24px;font-weight:620;letter-spacing:-.045em}` 被移除，结果变成 `.topbar h1,.topActions{display:flex;align-items:center;gap:16px}`。仍在使用的工作台标题因此失去字号、字重、字距和边距设置，并被错误纳入操作区的 flex 规则。
- 复现：在大于 760px 的桌面视口登录，进入“对话”“知识库”或“文档”，检查顶部知识库名称的 `h1` 样式。对基线和目标 CSS 运行相同的内存 DOM 样式探针，基线得到 `display:block; font-size:24px; font-weight:620; margin-top:7px; margin-bottom:0px`，目标得到 `display:flex; font-size:2em; font-weight:bold`，且不再有上述显式边距。
- 影响：在通常的 16px 默认字号下，桌面工作台标题由 24px 变为 32px，字重、标题留白及与上传操作区的排列高度发生回归。移动端虽另有 20px 字号覆盖，字重与边距丢失仍存在。此处影响的是继续保留的工作台，而非新增登录页或首页。
- 建议：恢复独立的 `.topbar h1` 排版规则，让 `.topActions` 独立使用 flex；删除旧登录样式时仅移除 `.authCard h1`。随后核验桌面与移动端的工作台标题及上传操作区布局。
