# 审阅记录

本目录归 Q（Code Review Agent）所有；审阅记录由 Q 填写，作者不得自写审阅结论。

## 审阅记录模板

```text
任务/作者：
审阅BASE_SHA → TARGET_SHA：
任务契约及验收范围：
实际阅读/执行的证据：
问题：严重度、位置、触发条件、影响、修复验收建议
非阻断建议/未验证事项：
结论：ACCEPTED / CHANGES_REQUESTED / BLOCKED
修复SHA及复核结论：
集成后新增差异与验证：
最终适用的代码版本：
```

规则：结论绑定具体 SHA；作者修复、冲突处理或集成后新增差异必须复核其影响；纯记录提交不改变已审代码结论，任何实现、契约、运行配置变化都不能用“只更新记录”规避复核。
