# PR 与独立审阅模板

## 作者提交信息

- 任务 ID / 标题：
- 负责人 / 实际作者 / 文件所有权：
- 依赖及已通过版本：
- Base SHA → Target SHA：
- 分支 / worktree：
- 目标及本次不做：
- 变更范围：
- 验证命令、环境、结果：
- 未运行项目及原因：
- 数据/隐私/许可证边界：
- 已知风险与后续任务：

## Q 审阅（仅由独立审阅者填写）

- 审阅 Base SHA → Target SHA：
- 核查的需求、实现和证据：
- 阻断问题：触发条件 / 影响 / 文件位置 / 修复验收：
- 非阻断建议 / 未验证项：
- 结论：BLOCKED / CHANGES_REQUESTED / APPROVED
- 修复 SHA / 复核：
- 合并后新增差异及集成检查：
- 适用最终 SHA / 最终任务状态：

本文件是仓库模板，不是审阅意见。作者不能代替 Q 标记 APPROVED。
