# Web 前端（M 所有）

职责：Next.js / React / TypeScript 用户体验，包括登录、知识库、上传状态、问答、来源核验和历史记录。

当前仅为目录组织占位，未建立 package manifest 或实际页面。实现前置：KF2-004 的共享契约及 KF2-008 前端骨架；Mock 只能用于开发，必须可见地区分，不能代替真实端到端验收。

配置约定：无密钥配置示例可放在本目录；浏览器只访问 Java API，不直接携带模型 API Key 调用供应商。密钥不得放进 NEXT_PUBLIC 环境变量。

启动：尚不可启动。M 在 KF2-008 建立并锁定前端依赖后补充可复现命令。
