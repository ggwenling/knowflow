# KnowFlow Web v2 设计规范（v1 交付基线）

适用范围：`apps/web-v2` 全部页面与状态。风格依据首页与登录页既有的黑白编辑感，工作区不再保留蓝灰旧样式。

## 1. 设计立场

像一本排版精确的产品手册，而不是通用后台。

- 衬线大字建立记忆点，细线、序号与留白建立秩序。
- 彩色只出现在状态、数据与危险操作处。
- 全站只保留一个高光动效：首页与登录页的 Three.js 波浪。其余交互动效 120–260ms。
- 不使用重阴影、玻璃拟态、大面积渐变或多色卡片。
- 工作区保持中文；登录/注册保留英文品牌语气。

## 2. 设计令牌

定义在 `src/app/globals.css`。

| 类别 | 值 |
|---|---|
| 背景 | `#FFFFFF`、`#FAFAFA`、`#F5F5F5` |
| 文字 | `#111111`、`#666666`、`#8C8C8C` |
| 边框 | `#EAEAEA`、`#D5D5D5` |
| 语义色 | 信息 `#5C7A8F`、成功 `#5F8A73`、警告 `#B0804A`、危险 `#A05A50` |
| 圆角 | 6 / 9 / 14 / 20 / 999px |
| 间距 | 4 的倍数；区块间距 18–30px；页面左右 24–52px |
| 动效 | `120ms` 快速 / `180ms` 常规 / `260ms` 慢速，缓动 `cubic-bezier(.22,.61,.36,1)` |
| 布局 | 侧栏 `248px`（≤1180px 为 226px），内容最大宽度 `1280px` |
| 字体 | `DM Sans` 正文；`DM Serif Display` 标题；中文回退 `PingFang SC` / `Microsoft YaHei` |

## 3. 排版

| 角色 | 字号 | 用法 |
|---|---|---|
| 品牌 / 页面主标题 | `clamp(30px, 3.2vw, 42px)`，首页 `clamp(54px, 5.6vw, 84px)` | 衬线、字重 400、`letter-spacing: -.03em` |
| 登录主标题 | `clamp(46px, 13vw, 90px)` | 衬线、行高 1 |
| 区块标题 | 13–15px / 600 | 无衬线，句子式大小写 |
| 正文 | 13–15px / 1.7–1.9 | 无衬线 |
| 辅助信息 | 11–12px | 无衬线，`#8C8C8C` |
| 控件文字 | 不低于 12px | 按钮、标签、筛选 |
| 数字 | `font-variant-numeric: tabular-nums` | 时间、计数、大小 |

衬线字体只用于：品牌字、页面 h1、弹层标题、引用序号 01/02。不要用于按钮或密集列表。

## 4. 外壳与响应式

`src/components/shell/app-shell.tsx`

- 桌面：固定 248px 侧栏，包含品牌、主导航（首页/对话/知识库/工作流/设置）、知识库快捷入口与内联创建、最近问答、账户区。
- 主内容：使用 `<main id="main-content" tabIndex={-1}>`，最大 1280px 居中，上边距 34px；页面首个可聚焦元素是“跳到主要内容”。
- 导航、知识库卡片、历史记录必须是 `<a>`/`Link`，支持 Cmd/Ctrl+click、中键与新标签；创建、上传、提问、停止、删除等动作保持 `<button>`。
- `≤1180px`：侧栏 226px，内容留白 28px，对话资料栏收窄。
- `≤980px`：对话页隐藏独立历史栏与资料栏，改为“历史记录”“资料”抽屉。
- `≤760px`：侧栏变为顶部区域：品牌、横向导航、知识库横条、内联创建、最近问答；首页与对话页隐藏这一段以让主内容更快出现，设置入口收进右上角账户菜单。账户菜单移到右上角。
- `390px`：无横向滚动；表格类内容改为纵向堆叠；次要说明可隐藏。

## 5. 页面规范

### 5.1 首页 `/`

- 衬线 `KnowFlow` + 一句定位语 + 单行提问框，下方 Three.js 波浪；无 WebGL 时回退 `home-wave.webp`。
- 四个快捷操作：创建知识库、新建对话、上传文档、创建工作流；四项都落到真实路由或明确的占位页。
- “我的知识库”“最近问答”两栏细线卡片；空态给出唯一下一步。
- 通知弹层使用原生 `details`，点击外部不强制关闭但可按 Esc 关闭；账户菜单见外壳。
- 初始数据未到时提问按钮禁用；没有 READY 资料时按钮禁用并给出原因。

### 5.2 登录 / 注册 `/login`、`/register`

- 左侧表单，右侧 42% 起的 ribbon；`≤700px` ribbon 收为顶部窄带，无 WebGL 时回退 `login-ribbon.webp`。
- 输入框 58px 高、12px 圆角；提交按钮墨黑、15px 圆角。
- 错误以红棕文字出现在表单内，`role="alert"`；提交中按钮显示 `Please wait…` 并禁用。
- 已登录访问 auth 页自动回到 `/`。

### 5.3 对话 `/conversations`、`/conversations/[questionId]`

- 桌面三栏：历史 244px、问答自适应、资料 276px；历史按今天/昨天/更早分组，支持搜索与加载更多；搜索词写入 `?history=`，可刷新恢复。
- 答案：问题行 + 状态 + 复制/删除；流式期间纯文本 + 闪烁光标，完成后 Markdown 渲染；引用最多 5 条，序号衬线 01/02。
- 原文弹层：标题“原文依据”，首焦点为“关闭原文”，Esc 关闭并回到触发引用；PDF 用 iframe `#page=N`，文本用 `pre`。
- 提问框固定在答案列底部，`Enter` 发送、`Shift+Enter` 换行；生成中显示“停止生成”。
- 单轮问答必须明示“每次提问独立检索”，不得伪装多轮上下文。
- 空态提供三条示例问题；失败/取消显示“此问答状态：…。可在历史记录中查看。”。
- `≤980px` 历史与资料改为抽屉，抽屉内复用同一组件与数据。

### 5.4 知识库 `/knowledge-bases`

- 页头：标题（有库为“我的知识库”，无库为“开始整理你的资料”）、说明、主行动“新建知识库”。
- 搜索按名称过滤并写入 `?q=`；卡片为链接（细线 + 文件夹图标 + 名称 + 更新时间 + 箭头）；删除按钮低饱和红棕，点击进入确认对话。
- 空态：说明价值与下一步，主行动聚焦侧栏创建输入。
- 列表接口不返回每个知识库的文档数，因此不展示编造的数量；文档数在详情页展示。

### 5.5 知识库详情 `/knowledge-bases/[baseId]`

- 返回、标题、`N 份资料 · M 份可用于问答`、私有空间标识。
- 上传区：虚线细框，支持拖拽与选择；TXT/MD/PDF，最大 8 MiB，PDF 200 页。
- 筛选：全部 / 已就绪 / 处理中 / 失败，带计数；筛选写入 `?status=`，非法值回退到“全部”。
- 文档行：格式徽标、名称、大小、状态点 + 文案、操作菜单（更新资料、重建索引、删除资料）。
- 删除走确认对话；轮询 1.5s 起指数退避至 4s，切换知识库或卸载时判旧退出。
- 无权限/不存在时展示 `role="status"` 的中文 404 文案，不泄漏资源是否存在。
- 文档接口不返回更新时间，因此文档行只展示大小与状态。

### 5.6 设置 `/settings`

- 两栏信息行：登录邮箱、空间、知识库数量、模型模式、问答方式、资料范围。
- 退出登录为危险按钮；明确“自助找回密码、团队协作、账单与导出暂未开放”。

### 5.7 工作流 `/workflow`

- 诚实的占位页：三步说明（上传资料 → 建立索引 → 带引用回答），明确“工作流功能暂未开放”，并提供前往知识库/对话的行动。
- 不使用假开关、假进度或假运行记录。

### 5.8 全局状态

- 会话加载：居中“正在检查登录状态…”；失败：卡片 + “重试连接”。
- 404：`not-found.tsx`；渲染错误：`error.tsx` / `global-error.tsx`，提供重试。
- 未登录访问工作区自动跳转 `/login`；401 触发全局会话失效提示并清理。

## 6. 组件

| 组件 | 路径 | 规则 |
|---|---|---|
| Button | `ui/button.tsx` | primary / secondary / ghost / danger / text；高度 32/38/46 |
| Dialog | `ui/dialog.tsx` | Radix；桌面居中、移动端底部抽屉；焦点陷阱与 Esc |
| ConfirmDialog | `ui/confirm-dialog.tsx` | 危险操作；标题说明后果，主按钮“确认删除” |
| EmptyState | `ui/empty-state.tsx` | 图标 + 一句标题 + 一句说明 + 唯一下一步 |
| Skeleton | `ui/skeleton.tsx` | 低对比扫光，只用于首屏列表 |
| StatusBadge | `ui/status-badge.tsx` | 5px 状态点 + 文案；成功/处理中/失败/取消/中性 |
| Toast | `sonner` | 仅用于异步操作结果，文案短、可关闭 |

按钮文字使用动词；同一动作在按钮、Toast、确认框中保持同名。导航用链接、动作用按钮；不要用 `div` 模拟控件。

表单补 `name`、`autoComplete`、`spellCheck`；占位符以 `…` 结尾并展示示例格式。输入、选择器与 textarea 必须有可见焦点环，不得只写 `outline: none`。

## 7. 动效

- 首页/登录：Three.js 波浪为唯一高光；页面不可见时暂停，减少动态效果时只绘制静态帧。
- 页面进入：180–260ms 淡入 + 6–8px 位移；列表卡片 45ms 递增延迟。
- 流式答案：50ms 缓冲刷新，避免逐字触发整棵树重渲染；完成后一次性解析 Markdown。
- Hover 只改变边框、底色与 2px 位移；不使用缩放弹跳。
- `prefers-reduced-motion: reduce` 下关闭所有非必要动画与过渡。

## 8. 可访问性

- 焦点环统一 `2px #555`，偏移 2–3px；不得移除 outline。
- 图标按钮必须有 `aria-label`；菜单使用 `role="menu"` / `role="menuitem"`。
- 弹层使用 Radix Dialog：焦点陷阱、Esc 关闭、关闭后回到触发元素。
- 流式答案容器 `aria-live="polite"`；加载/错误使用 `role="status"` / `role="alert"`。
- 键盘可完成：登录、提问、打开引用、关闭弹层、切换知识库、打开移动抽屉。
- 对比度：正文 `#111` / `#666` 于白底，辅助信息不低于 `#8C8C8C` 且不承载唯一关键信息。
- 弹层与抽屉设置 `overscroll-behavior: contain`；可点区域设置 `touch-action: manipulation`；不要禁用缩放。
- 历史列表超过 50 项使用 `content-visibility: auto` 与 `contain-intrinsic-size`，避免一次性布局全部行。

## 9. 数据与接口边界

- 契约冻结 `0.2.0`；前端只通过同源代理 `/api/v1` 访问，不直连后端。
- 保留 SSE 事件序号、顺序、`request_id`、契约版本校验，不因界面放宽。
- 删除知识库复用 `DELETE /api/v1/knowledge-bases/{id}`；删除前明确“资料将不可见且无法恢复”。
- 不编造统计、更新时间、文档数或模型能力；合成模型必须显示提示。
